# Beecrowd

Exercícios resolvidos da plataforma [Beecrowd](https://www.beecrowd.com.br/) (antigo URI Online Judge), em **Python**, com foco em lógica de programação: entrada/saída, laços de repetição, condicionais e manipulação de strings e números.

## Exemplos

- `numero_secreto.py`, `media.py`, `par.py` — lógica básica
- `while.py`, `while2.py`, `for.py`, `for2.py`, `continue.py` — estruturas de repetição
- `string_01.py`, `string_02.py` — manipulação de strings
- `area-do-círculo.py`, `Tabuada.py`, `Anos bissextos.py`, `Triângulo alfabético.py` — exercícios matemáticos e de lógica
