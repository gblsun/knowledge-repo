# site ti é aqui

Site institucional fictício de uma loja/prestadora de serviços de TI ("TI é Aqui"), em HTML/CSS/JS, com páginas de produtos, serviços, contato, dúvidas e localização.

## Estrutura

- `index.html` — página inicial
- `produtos.html`, `serviços.html` — catálogo de produtos e serviços
- `Contatos.html`, `duvidas.html`, `localização.html`, `pesquisa.html`, `linguagem.html` — páginas complementares
- `assets/` — CSS, JS e SASS
- `images/` — imagens do site (produtos, ícones, logos)
- `gcw.pptx` — apresentação do projeto
