# Projeto Cripto

Site em HTML sobre criptomoedas: explicações gerais e páginas dedicadas a moedas/projetos específicos.

## Estrutura

- `Criptomoeda/index.html` — página principal do site
- `Criptomoeda/Como surgiu.html`, `Criptomoeda/Como funciona.html` — conceitos gerais
- `Criptomoeda/Satoshi.html`, `Criptomoeda/Etherum.html`, `Criptomoeda/Axie Infinity.html`, `Criptomoeda/Mobox.html`, `Criptomoeda/LightNite.html`, `Criptomoeda/Raca.html`, `Criptomoeda/Squid.html` — páginas de moedas/projetos específicos
