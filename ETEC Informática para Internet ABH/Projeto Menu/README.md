# Projeto Menu

Site simples em HTML/CSS com menu de navegação entre páginas temáticas (eletrônica, farmácia, jogos, informática).

## Estrutura

- `Menu/index.html` — página inicial com o menu
- `Menu/eletronica.html`, `Menu/farmácia.html`, `Menu/jgs.html`, `Menu/Infonet.html`, `Menu/adm.html` — páginas de destino
- `Menu/estilos.css` — estilização
