# Interfaces Web

Atividades de HTML e CSS com foco em estilização de interfaces: formatação de texto, tabelas e lições introdutórias.

## Estrutura

- `Lição no1/`, `Lição no2/` — lições introdutórias de HTML/CSS
- `Atividade - Formatação de Texto (CSS)/` — estilização de texto com CSS
- `tabela/` — estilização de tabelas com CSS
- `13 Ativ. 3ºBim Tabela Estilo CSS (Prática)/` — atividade avaliativa de tabela com CSS
