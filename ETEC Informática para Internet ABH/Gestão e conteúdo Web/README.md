# Gestão e conteúdo Web

Trabalhos práticos de HTML e CSS para gestão e publicação de conteúdo web.

## Estrutura

- `trabalho 1/`, `trabalho 2/`, `trabalho 3/` — páginas HTML/CSS de fixação
- `trabalho 4/` — mini-site com múltiplas páginas (eletrônica, farmácia, infonet, jogos)
- `gcw3.html` — atividade avulsa
