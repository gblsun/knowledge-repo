# Projeto Prático

Site de portfólio em HTML/CSS apresentando estilos musicais ao longo da história (Renascentista, Barroco, Clássico, Romântico, Impressionismo, Contemporâneo, Jazz), com formulário de contato e créditos.

## Estrutura

- `index.html` — página inicial
- `Renascentista.html`, `Barroca.html`, `Clássico.html`, `Romântico.html`, `Impressionismo.html`, `Contemporâneo.html`, `Jazz.html` — páginas de cada estilo musical
- `formulario.html`, `Créditos.html`, `Leia-me.txt` — páginas complementares
- `css/`, `images/` — recursos de estilo e imagens
