# ETEC — Informática para Internet

Materiais do curso técnico em Informática para Internet (ETEC ABH), com foco em desenvolvimento web, programação e fundamentos de TI.

## Disciplinas e projetos

- [Programação e algoritmos](./Programação%20e%20algoritmos/) — lógica de programação em C
- [Gestão e conteúdo Web](./Gestão%20e%20conteúdo%20Web/) — gestão de conteúdo para web
- [Interfaces Web](./Interfaces%20Web/) — HTML e CSS aplicados a interfaces
- [Projeto Prático](./Projeto%20Prático/) — site de portfólio sobre estilos musicais
- [Projeto Menu](./Projeto%20Menu/) — projeto de menu web
- [Projeto Cripto](./Projeto%20Cripto/) — projeto sobre criptomoedas
- [Projetos com DreamWeaver](./Projetos%20com%20DreamWeaver/) — sites construídos com Adobe DreamWeaver
- [site ti é aqui](./site%20ti%20é%20aqui/) — site institucional fictício de loja de TI
