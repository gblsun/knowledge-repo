# Matemática para Computação

Disciplina de fundamentos matemáticos aplicados à computação: lógica matemática, conjuntos e raciocínio quantitativo usado como base para algoritmos e estruturas de dados.

**Curso:** Bacharelado em Ciência da Computação — IMPACTA (nome oficial: *Matemática para a Computação*)
**Semestre:** 2º | **Carga horária:** 80h

## Ementa oficial

Números reais. Sistema de coordenadas cartesianas. Funções reais de uma variável real (par, ímpar, periódica, monótona, bijetora, composta, inversa). Funções linear, afim, potenciais, racionais, exponenciais, logarítmicas, trigonométricas e inversas. Números complexos: operações, propriedades e raízes.
