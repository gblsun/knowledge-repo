# Linguagem Orientada a Objeto

Introdução à programação orientada a objetos em **Python**: classes, objetos, atributos, métodos e exercícios práticos de modelagem (aluno, conta bancária, retângulo, pessoa).

**Curso:** Bacharelado em Ciência da Computação — IMPACTA (nome oficial: *Linguagem Orientada a Objetos*)
**Semestre:** 4º | **Carga horária:** 80h

## Ementa oficial

Introdução à programação orientada a objetos; classes e métodos; encapsulamento e sobrecarga; sobreposição de métodos; construtores e destrutores; herança; polimorfismo e ligação dinâmica; aplicações e estudos de caso. A ementa oficial usa Java como linguagem de referência; os exercícios deste repositório foram feitos em Python.

## Estrutura

- `Aula - 07.08/` — operador ternário, tipos e cópia de dados, exercícios
- `Aula - 27.08/` — exemplos e exercícios de aula
- `Exercício de Classe e Objeto + Exemplo (Pessoa)/` — modelagem de classes (Aluno, ContaBancaria, Retângulo)
- `resolucaoExercicios/` — resolução de exercícios (conjuntos, dicionários)
