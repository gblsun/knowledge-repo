# Inteligência Computacional

Projeto de análise de dados aplicando técnicas de inteligência computacional, com relatórios executivos e técnicos gerados a partir de uma base de emissões de gases do efeito estufa no Brasil (SEEG).

**Curso:** Bacharelado em Ciência da Computação — IMPACTA
**Semestre:** 5º | **Carga horária:** 80h

## Ementa oficial

Introdução à Inteligência Artificial (IA). Métodos de busca (cega, heurística, competitiva). Representação do conhecimento e sistemas baseados em conhecimento. Paradigmas de programação lógico e funcional. Aprendizado de máquina supervisionado e não supervisionado. Aplicações de IA: processamento de linguagem natural, jogos, robótica e mineração de dados.

## Estrutura

- `projetofinal-testes/` — notebook de análise, base de dados (SEEG) e relatórios (executivo e de análise) em HTML
