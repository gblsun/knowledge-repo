# Análise Exploratória de Dados

Prática de análise exploratória de dados (EDA) em **Python** (pandas, notebooks Jupyter), incluindo estatística descritiva, visualização e detecção de outliers com boxplots.

**Curso:** Bacharelado em Ciência da Computação — IMPACTA
**Semestre:** 5º | **Carga horária:** 80h

## Ementa oficial

Fundamentos de análise de dados. Análise de distribuição univariada e bivariada. Correlação e regressão linear. Análise, interpretação e comunicação de padrões presentes nos dados por meio de diferentes técnicas de visualização.

## Estrutura

- `Atividade Prática 1 - dataset iris/` — EDA do dataset Iris
- `Atividade Prática 2 - dataset penguins/` — EDA do dataset Penguins
- `lista03/` — exercícios de boxplot (funcionários, tempos, memória, projeto)
