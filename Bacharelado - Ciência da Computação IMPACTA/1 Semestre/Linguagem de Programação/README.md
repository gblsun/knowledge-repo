# Linguagem de Programação

Disciplina introdutória do curso, com primeiro contato com lógica de programação usando **Python**: variáveis, tipos de dados, estruturas condicionais, laços de repetição e funções básicas.

**Curso:** Bacharelado em Ciência da Computação — IMPACTA
**Semestre:** 1º | **Carga horária:** 80h

## Ementa oficial

Introdução e conceitos de programação e linguagem de programação. Linguagem de programação Python. Tipos de dados. Estruturas lógicas ou de controle de fluxo. Modularização.
