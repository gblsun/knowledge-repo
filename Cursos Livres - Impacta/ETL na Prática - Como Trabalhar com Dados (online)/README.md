# ETL

Curso prático de **ETL (Extract, Transform, Load)** em Python, com pandas, SQLite e arquivos Excel/HTML, organizado por etapa do pipeline.

## Estrutura

- `1. Extract - Extração/` — extração de dados (pandas, HTML)
- `2. Transform - Transformação/` — transformação de dados
- `3. Load - Carregar/` — carregamento em banco de dados
- `4. Projeto de Análise de Dados/` — projeto final integrando as três etapas
- `material_de_apoio/` — notebooks e datasets de apoio extras
